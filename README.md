## 👨‍💻 About Me

I'm a developer who builds systems end to end: desktop applications in **Java** with MVC architecture, web pages with **HTML, CSS and JavaScript**, relational databases in **MySQL, MariaDB and PostgreSQL**, and the **Linux servers** where applications run.

Besides programming, I model data, set up secure user access and support helpdesk systems. I like to understand a system as a whole: from the interface to the database and the server.

### 🎯 What I can do
* ☕ **Build Java applications** (Swing, MVC, DAO) backed by databases
* 🌐 **Create web pages** with HTML, CSS and JavaScript
* 🗄️ **Design databases** (ER diagrams, data dictionaries) and write SQL queries
* 🔐 **Control access by roles**, store passwords with hashing (bcrypt) and keep audit logs
* 🐧 **Install and manage** Ubuntu servers with Apache and MariaDB
* 🛠️ **Administer GLPI**: email notifications, plugins, testing and portal customization

> **💡 Approach:** understand the problem ➔ model the solution ➔ build it ➔ test it ➔ improve it.
